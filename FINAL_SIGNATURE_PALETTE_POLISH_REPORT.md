# CameraGuard final signature palette polish

Applied the requested palette across the current latest project state:
- Midnight `#040521` as the primary dark background.
- Deep blue `#081D56` for cards, navigation surfaces and map/HUD depth.
- Sky blue `#62AAE5` for route, active navigation, primary controls and location emphasis.

Also aligned Material 3 dark/light schemes, MapLibre roads-only styling, HUD WebGL/CSS route materials, navigation widgets, community accents and remaining legacy cyan surfaces. Emergency red and success green were intentionally retained as semantic safety colours.

No product/feature behaviour was intentionally changed in this pass.
